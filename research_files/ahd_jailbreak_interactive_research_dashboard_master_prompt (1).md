3. **Spectral Hypergraph Convolution & Risk Formulas**:
   * Build $\mathbf{H}_t \in \{0,1\}^{|\mathcal{V}_t| \times |\mathcal{E}_t|}$, vertex degrees $d(v) = \sum_{e} w_t(e) H_t(v,e)$, hyperedge degrees $\delta(e) = \sum_{v} H_t(v,e)$, and normalized propagation operator:
     $$\mathbf{P}_t = \mathbf{D}_v^{-1/2} \mathbf{H}_t \mathbf{W}_t \mathbf{D}_e^{-1} \mathbf{H}_t^\top \mathbf{D}_v^{-1/2}$$
   * Compute the three risk components for active node subset $\mathcal{A}_t \subseteq \mathcal{V}_t$:
     * **Hyperedge Overlap Score ($S_{\text{edge}}$)**: Sum of $w_t(e) \cdot \frac{|\mathcal{A}_t \cap e|}{|\mathcal{A}_t|}$ across unsafe hyperedges with $|\mathcal{A}_t \cap e| \ge 2$.
     * **Spectral Subspace Risk ($S_{\text{spec}}$)**: Normalized risk projection from propagated node embeddings $\mathbf{X}^{(1)} = \mathbf{P}_t \mathbf{X}^{(0)}$.
     * **Higher-Order Structural Anomaly ($S_{\text{anom}}$)**: When any policy node (`pol:*`) co-occurs with any adversarial framing/escalation node without purely benign context, compute $S_{\text{anom}} = \text{clip}(0.60 + 0.35 \cdot (1 - \min(\text{maxKnownOverlap}, 0.85)), 0, 1)$.
     * **Unified Pre-Inference Risk Score**:
       $$R(p_t) = \text{clip}\left(\lambda_1 S_{\text{edge}} + \lambda_2 S_{\text{spec}} + \lambda_3 S_{\text{anom}}, \; 0, \; 1\right)$$
       (With default $\lambda_1 = 0.35, \lambda_2 = 0.25, \lambda_3 = 0.55$, and $\tau_{\text{block}} = 0.52$. In Static Baseline mode, $\lambda_3 = 0$, $\lambda_1 = 0.75, \lambda_2 = 0.15$, and online updates are turned off.)
   * **Online Adaptation Rules** (when $R(p_t) \ge \tau_{\text{block}}$ in Adaptive Mode):
     * **Weight Reinforcement**: $w_{t+1}(e) = \min(2.0, \; \gamma w_t(e) + \alpha R(p_t))$.
     * **Dynamic Hyperedge Expansion**: If $\text{maxKnownOverlap} < \eta_{\text{novel}}$ (`0.65`) and $|\mathcal{A}_t| \ge 2$, spawn `he_adaptive_emerging_k` connecting all nodes in $\mathcal{A}_t$ with initial weight $w_0 = \text{clip}(1.20 + 0.30 R(p_t), 1.0, 1.8)$.
